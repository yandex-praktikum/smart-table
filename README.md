# Умная таблица

Стартовый код практической работы «Умная таблица».

## Запуск

Нужен Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite, — обычно http://localhost:5173/. Остановить сервер — `Ctrl + C`.

## Что в стартере

- `index.html` — вёрстка таблицы, шаблоны строки (`#row`) и кнопки страницы (`#page`);
- `src/data.js` — строки таблицы и список продавцов, готово;
- `src/main.js` — точка входа: элементы страницы, состояние таблицы, функция `render()`;
- `src/table.js`, `src/searching.js`, `src/filtering.js`, `src/sorting.js`, `src/pagination.js` — функции, которые вы напишете;
- `src/lib/pages.js` — готовая функция `getPages()`: какие номера страниц показать.

Задание и порядок шагов — в уроке «Практическая работа 6.2 „Умная таблица“».
